# Toppers drop-in

One folder per class. Replace `photo.webp` (or `.jpg` / `.png`) and edit `card.txt`, then run `python _build_pages.py` and push `main`.

`card.txt` format:

```
Name in English
नाम हिंदी में

English saying.

हिंदी वचन।
```

Empty folders (no photo) are skipped. Family consent is required before a real child’s portrait goes up.
